## Research focus

The numerical method and its implementation need to work together. My research considers the performance, portability and scalability of high-order CFD algorithms on modern high-performance computing systems.

UCNS3D provides a practical setting for developing a common CPU and GPU implementation while preserving the numerical formulation and assessing the resulting solutions.

## Implementation themes

- Standards-based GPU offload and a shared source code.
- Data layout and memory access for unstructured numerical algorithms.
- Parallel communication and scaling of complete simulation workflows.
- Verification of numerical behaviour across computing architectures.

Performance results are reported with their benchmark, numerical configuration and hardware context in the associated publications.
